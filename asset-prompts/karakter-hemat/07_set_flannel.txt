PROMPT (salin semua teks di antara garis)
---------------------------------------------------------------------
Use the attached reference image as the strict style guide. Match its exact pixel art style: same outline thickness and color, same shading and highlight style, same level of detail, same top-down 3/4 perspective and the same color palette. The new asset must look like it belongs to the same game as the reference.

Pixel art, 16-bit style, top-down 3/4 view like Stardew Valley and classic SNES RPGs, crisp hard pixel edges, no anti-aliasing, no blur, no gradients, limited palette. Theme: a modern, clean and cozy computer science faculty. Base colors deep navy #1B2A41, slate grey #4F5D6E, cream #F7F5F0 and warm wood #9C6B43; soft orange #E8833A highlights; cyan #3FC1C9 only for screens and LEDs. No text, no readable letters.

Draw a sprite sheet of a HEADLESS chibi body (neck stump visible, NO head) wearing this outfit:
light grey open flannel shirt with a check pattern over a plain dark t-shirt, khaki cargo trousers with side pockets, dark sneakers.
Use exactly the same body size, proportions, chibi shape and pixel scale as the headless hoodie bodies in the reference image. Layout: exactly 2 rows x 6 columns, evenly spaced, every body the same height.
Row 1: facing down (toward viewer) - left foot step, standing, right foot step; then facing up (back view) - left foot step, standing, right foot step.
Row 2: facing left in pure side profile - back foot step, standing, front foot step; then facing right in pure side profile - back foot step, standing, front foot step.
Arms and legs swing naturally in the step frames. The main top garment must be LIGHT GREY so the game can recolor it; bottoms and shoes keep their real colors. Do not draw any heads.

Classic hand-pixeled 16-bit JRPG sprite art, NOT vector, NOT flat design, NOT geometric shapes, NOT an icon. Each material has 3 to 4 shades (highlight, base color, shadow, dark outline), consistent light from the top-left, organic rounded silhouettes, visible hair strands and cloth folds, selective dark outlines.

Solid flat magenta #FF00FF background.
