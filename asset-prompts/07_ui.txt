=====================================================================
 07 · ANTARMUKA (UI) — GAYA TERMINAL / EDITOR KODE
=====================================================================
Konsep: UI meniru jendela aplikasi yang akrab bagi mahasiswa informatika:
  - kotak dialog       -> jendela terminal (bilah judul + titik tiga warna)
  - daftar materi      -> panel penjelajah file (folder & file) ala editor kode
  - panel kuis         -> jendela editor kode dengan nomor baris
Tetap memakai palet utama: bingkai navy, isi krem (mudah dibaca), aksen oranye.
Versi gelap (isi navy, teks terang) boleh dibuat sebagai opsi "mode gelap".

Prinsip: AI cukup membuat BINGKAI dan TOMBOL. Semua teks, daftar materi,
soal kuis, dan nama pemain diisi oleh game. Bingkai dibuat "9-slice":
sudut tetap, sisi bisa diperpanjang.
