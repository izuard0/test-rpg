Pengulangan

Setiap pengulangan punya badan dan kondisi berhenti.

for … endforwhile … endwhilerepeat … until

Bagian 1 · Mengapa pengulangan

Tulis sekali, jalankan seratus kali

Tanpa pengulangan

write('Hello World')
write('Hello World')
write('Hello World')
... { 100 kali? }

Dengan pengulangan

for i ← 1 to 100 do
   write('Hello World')
endfor

Keluaran di layar

Putaran ke-

0 / 100i ← 1

Badan

Langkah yang diulang: write('Hello World').

Kondisi berhenti

Kapan pengulangan selesai: setelah i melewati 100.

Perubahan

Langkah yang membuat kondisi suatu saat terpenuhi: i naik 1 setiap putaran.

Arahkan kursor ke kartu untuk menyorot bagian pseudocode. Notasi mengikuti Munir (2019).

Bagian 1 · for

for: banyak ulangan sudah diketahui

ALGORITMA:
   read(N)
   jumlah ← 0
   for i ← 1 to N do
      jumlah ← jumlah + i
   endfor
   write(jumlah)

Menghitung mundur: downto

for i ← 10 downto 1 do
   write(i)
endfor
write('Meluncur!')
!

Aturan for

Pencacah naik (atau turun) 1 secara otomatis. Jangan ubah pencacah di dalam badan.

Bagian 1 · while

while: periksa dulu, baru kerjakan

Berapa bulan sampai tabungan mencapai target? (bunga 0,5% per bulan)

ALGORITMA:
   read(saldo, setoran, target)    { setoran > 0 }
   bulan ← 0
   while saldo < target do
      saldo ← saldo + saldo * 0.005 + setoran
      bulan ← bulan + 1
   endwhile
   write(bulan, saldo)
?

Kapan dipakai

Banyak ulangan tidak diketahui sebelumnya, dan mungkin nol kali.

!

Pastikan berhenti

saldo bertambah setiap putaran, jadi saldo < target suatu saat false. Karena itu setoran > 0.

Bagian 1 · repeat-until

repeat-until: kerjakan dulu, baru periksa

Validasi: paksa nilai 0..100

repeat
   write('Masukkan nilai (0..100): ')

until (nilai ≥ 0) and (nilai ≤ 100)

Bagian 2 · Akumulator · pencacah · sentinel
Tiga pola dalam satu kasir

  


ALGORITMA:
   total ← 0                  { akumulator }
   banyak ← 0                 { pencacah }
   read(harga)
   while harga ≠ 0 do         { 0 = sentinel }
      total ← total + harga
      banyak ← banyak + 1
      read(harga)
   endwhile
   if total > BATAS_DISKON then
      diskon ← 0.1 * total
   else
      diskon ← 0
   endif
   write(banyak, total, diskon, total - diskon)

Bagian 3 · Kapan perlu larik
Larik diperlukan saat data harus dipakai lagi

  


ALGORITMA:
   read(N)

      read(nilai[i])
   endfor

   for i ← 1 to N do

         banyak ← banyak + 1
      endif

Bagian 3 · Pencarian
Pencarian beruntun berhenti begitu data ditemukan

  


ALGORITMA:
   { anggap N dan nim[1..N] sudah terisi }
   read(dicari)
   ketemu ← false
   i ← 1
   while (i ≤ N) and (not ketemu) do
      if nim[i] = dicari then
         ketemu ← true
      else
         i ← i + 1
      endif
   endwhile
   if ketemu then
      write('ditemukan pada posisi ', i)
   else
      write('tidak ditemukan')
   endif

Studi kasus · langkah 1–4
Studi kasus: rekap nilai kelas

  
Masalah
Baca nilai N mahasiswa (N ≤ 60, nilai 0–100, masukan tidak sah diminta ulang). Tampilkan rata-rata, nilai tertinggi, nilai terendah, banyak yang lulus (≥ 60), dan banyak yang di atas rata-rata.

  

    

      
MasukanProsesKeluaran

      
N, 1 ≤ N ≤ 60validasi masukanrata-rata

      
nilai[1..N], 0–100jumlah, tertinggi, terendah, lulustertinggi, terendah

      
rata-rata, lalu banyak di atas rata-ratalulus, di atas rata-rata

    

    

      
Dekomposisi
  1. Baca dan validasi data
  2. Satu telusur: jumlah, tertinggi, terendah, lulus
  3. Rata-rata
  4. Telusur kedua: di atas rata-rata
  5. Tampilkan

      
[ ]
Keputusan data
“Di atas rata-rata” butuh setiap nilai dua kali → simpan di larik.

    

  







  
Studi kasus · langkah 5a
Rekap nilai kelas: deklarasi dan validasi

  


PROGRAM RekapNilaiKelas
{ Membaca nilai N mahasiswa, lalu
  menampilkan rata-rata, nilai tertinggi,
  nilai terendah, banyak yang lulus
  (nilai ≥ 60), dan banyak yang di atas
  rata-rata. }

DEKLARASI
   const NMAKS = 60
   const BATAS_LULUS = 60
   nilai : array[1..NMAKS] of real
   N, i, lulus, diAtas : integer
   jumlah, rata : real
   terbesar, terkecil : real

    


ALGORITMA:
   { 1. Baca data, dengan validasi }
   repeat
      read(N)
   until (N ≥ 1) and (N ≤ NMAKS)
   for i ← 1 to N do
      repeat
         read(nilai[i])
      until (nilai[i] ≥ 0) and (nilai[i] ≤ 100)
   endfor

      
↻
Validasi bersarang
repeat-until di dalam for: setiap elemen diminta ulang sampai sah. Konstanta membuat batas mudah diubah.

Rekap nilai kelas: pemrosesan dan keluaran

  
akumulatormaksimumminimumpencacah bersyarat

  


   { 2. Telusur pertama }
   jumlah ← 0
   terbesar ← nilai[1]
   terkecil ← nilai[1]
   lulus ← 0
   for i ← 1 to N do
      jumlah ← jumlah + nilai[i]
      if nilai[i] > terbesar then
         terbesar ← nilai[i]
      endif
      if nilai[i] < terkecil then

      endif

   { 3. Rata-rata }

   { 4. Telusur kedua }

      endif
   endfor
   { 5. Tampilkan hasil }
